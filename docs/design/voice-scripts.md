# Voice alert scripts (English)

Each voice alert is preceded by a soft two-note chime and ducks music. Plain, short, calm, imperative; numbers with units; no exclamation marks. English only (decided 2026-10-27).

| Alert | English | Notes |
|---|---|---|
| Junction ahead | Fork in 80 metres. Keep left, going uphill. | |
| Off route | Warning. You are 40 metres off the trail. Stop and check. | repeats with the 3-long haptic until resolved or snoozed |
| Back on route | Back on the trail. | |
| Wrong way | You are heading back to the start. Turn around to continue. | |
| GPS lost | GPS signal weak. Keep to the trail. | |
| GPS back | GPS is back. | |
| Friend behind | Rahul is 300 metres behind. | |
| Friend out of range | Rahul is out of range. He was last seen 340 metres behind, downhill. | |
| Regroup | Rahul is 210 metres behind. | |
| Friend SOS | Warning. Rahul sent an S.O.S. He is 340 metres away, uphill. | repeats until acknowledged |
| Lost mode | Stay where you are. Your group is coming to your last position. | |
| Fall countdown | Did you fall? Sending S.O.S. in 60 seconds. Tap I'm OK to cancel. | repeats at 30, 10 seconds |
| SOS active | S.O.S. active. Your position will be sent at first signal. | |
| SOS delivered | S.O.S. delivered to your contacts. | only when true |
| Quick message received | Rahul says: Take left fork. | |
| Sunset | Sunset in one hour. Camp is 4 kilometres away, about 1 hour 40 minutes. | |
| Storm warning | Pressure is dropping fast. Weather may turn. | |

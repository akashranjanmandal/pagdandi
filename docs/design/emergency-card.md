# Emergency card

Prototype: [emergency-card.html](emergency-card.html).

**Purpose:** a helper can read blood group, allergies, medicines and call contacts, even from the lock screen.

## Elements
Blood group at display size (the one thing a medic wants first); allergies and medicines as plain rows; contacts with Call keys (56 dp). View, Edit (blood group chips + text), and lock-screen view (read-only, "Unlock to edit").

## Reasons
Large and unadorned for stress; editing only after unlock so a stranger cannot change it.

## Accessibility
Call keys labelled with the contact name; edit fields labelled.
